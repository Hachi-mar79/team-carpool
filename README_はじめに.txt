チーム配車管理 PWA版

1. このフォルダ内の5ファイルを、HTTPS対応の静的サイトにアップロードします。
2. iPhoneのSafariで公開URLを開き、共有メニューから「ホーム画面に追加」を選択します。
3. データは各端末のブラウザ内に個別保存され、端末間では同期されません。
4. バックアップは「データをバックアップ」、復元は「バックアップを復元」を使用します。
5. インストール時にはインターネット接続が必要です。オフライン利用は初回読み込み・キャッシュ完了後に可能です。
6. 公開URLを知る人はアプリ画面を開けます。登録データはサイトへ自動送信しませんが、URLの公開範囲と端末の管理に注意してください。
7. この版は実機未検証です。まず個人情報を含まないダミーデータでテストしてください。
